Search and actions with data

Start new search​

This feature allows you to start new search.

You click on search box and write one or more keywords and then click on magnifying glass or click enter on your keyboard to run search. The system shows you the results.

Start new search

List of results

View details of the results​

This functionality allows you to view details of the data.

To view dataset details, click the “Show details” toggle. The system displays the dataset details.

Button for details of result

Dataset details

Saving data​

This functionality allows you to save data.

To save a dataset, click the bookmark icon.

Save data button

The dataset is added to the Saved Datasets section, click "Saved" button to navigate it.

Button to navigate section dedicated to data saved

Section dedicated to data saved

Delete all saved data​

This functionality allows you to delete all saved data.

To remove all saved datasets, click the Delete icon in the Saved Datasets page.

Delete all saved data button

Back to search​

This feature allows you to return to the search page from the Saved Datasets section.

To return to the search page, click the left-arrow icon in the top-left corner of the page.

Button to return to search interface

View Dataset​

This functionality allows you to view a dataset.

To view dataset, click the “View Dataset” button in corresponding data card.

View dataset button

Filter data​

This functionality allows you to filter data.

To filter the results, click one of the filter buttons above the dataset list.

Filter buttons
