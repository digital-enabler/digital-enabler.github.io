Frequently Asked Questions

Introduction & Strategic Overview​

What is the primary purpose of the KPI Manager?

KPI Manager helps organisations define, monitor, analyse and manage Key Performance Indicators (KPIs). It consolidates data from different sources and provides visualisations that support performance monitoring and decision-making.

Reference: Tool overview

Which types of organisations can benefit from KPI Manager?

KPI Manager is designed for scalability and can be used across a wide range of industries and application domains. Its flexible configuration allows organisations to adapt KPI monitoring to their specific needs.

Reference: Tool overview

Can KPI Manager integrate data from multiple sources?

Yes. KPI Manager acts as a central hub that aggregates and consolidates data from multiple systems and databases, providing a unified view of performance metrics.

Reference: Tool overview

Authentication, Navigation & Interface​

How do I access KPI Manager?

KPI Manager can be accessed through the application URL provided by your organisation. Users are redirected to the authentication page before entering the platform.

Reference: Access to the application

Which authentication system is used by KPI Manager?

KPI Manager uses the Keycloak Identity Management system to provide secure and standardised user authentication.

Reference: User login

Home Page, KPI List & General Management​

How can I view the list of KPIs?

After logging in, you are automatically redirected to the KPI list page. You can return to it at any time using the KPI menu options available in the interface.

Reference: View list of KPIs

How can I view detailed information about a KPI?

Click the KPI name in the list to open its detail page and review all available configuration and performance information.

Reference: View details of KPIs

KPI Configuration & Editing​

Who can edit a KPI?

Users belonging to the same context as the KPI, and with appropriate permissions, can modify its configuration.

Reference: Edit KPI

Which KPI properties can be edited?

Users can modify metadata such as name, code, description and category, together with formulas, measures, target values, units of measure and chart settings.

Reference: Edit KPI

How can I compare multiple KPIs?

Select the “Compare” option from the KPI menu, choose the KPIs, period and chart type, and run the comparison to visualise the results together.

Reference: Compare KPI

KPI Creation & Duplication​

What is the difference between a manual KPI and an automatic KPI?

Manual KPIs require users to enter values directly, whereas automatic KPIs calculate values using formulas, measures and scheduled executions.

Reference: Create new KPI

Can I create KPIs using existing measures?

Yes. Automatic KPIs can use measures and other KPIs within formulas to calculate new indicators.

Reference: Create new KPI

Common KPIs & Collaboration​

What are Common KPIs?

Common KPIs are indicators defined by platform administrators and automatically shared across all active contexts to ensure consistent measurement practices.

Reference: Common KPI

How are Common KPIs activated within a context?

After a Common KPI is assigned, editors complete its configuration. Once saved, the KPI becomes active and accessible to authorised users within the context.

Reference: Common KPI Management - Editor

What is the role of an Administrator?

Administrators create and manage Common KPIs and have visibility across all active contexts within the tenant.

Reference: Roles

What is the role of an Editor?

Editors can create, edit and delete KPIs and metrics within their own context and configure Common KPIs received from administrators.

Reference: Roles

What is the role of a Viewer?

Viewers have read-only access to KPIs and metrics within their context and cannot modify any information.

Reference: Roles

Measures Management​

What is Measure?

A Measure, also called a Metric, is a raw quantitative or qualitative data point collected from a system source or manual input. Measures are the building blocks used to calculate KPIs.

Reference: Measures

What is the difference between a Measure and a KPI?

Measures represent raw operational data, while KPIs use one or more Measures to evaluate progress towards specific objectives or targets.

Reference: Measures

How can I access the measures section?

Click the ruler icon in the left sidebar to open the Measures page and view the list of available measures.

Reference: View list of measures

Notifications​

What are notifications used for in KPI Manager?

Notifications inform editors when a new Common KPI has been created by an administrator and requires configuration or evaluation within their context.

Reference: Notifications | Common KPI

How can I view my notifications?

Click the bell icon located in the top-right corner of the application. The system opens a notification window showing all available notifications.

Reference: Notifications

What happens when I select a notification?

Selecting a notification opens the related Common KPI, allowing you to complete its configuration or review its details.

Reference: Notifications
